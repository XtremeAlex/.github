# XtremeAlex/.github

Repo speciale dell'account: **governance centrale** di tutti i repository.

- **Health file di default** — CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, SUPPORT, template PR e issue:
  GitHub li applica ai repo pubblici dell'account che non ne hanno di propri.
- **`.ai/`** — costituzione, flussi Git, registro dei repository (la fonte unica delle regole comuni).
- **Workflow riusabili** — secret scan e commit lint chiamabili da qualsiasi repo
  (`uses: XtremeAlex/.github/.github/workflows/reuse-<nome>.yml@main`).
- **`AGENTS.md`** — istruzioni per gli assistenti AI valide in ogni repo.
