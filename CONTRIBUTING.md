# Contributing

Grazie per l'interesse. Questo progetto segue lo standard comune dell'account:
leggi prima [`.ai/core.md`](.ai/core.md) e [`.ai/flussi.md`](.ai/flussi.md) del repo `XtremeAlex/.github`.

In breve:

1. **Branch**: lavora da `develop` (o `feature/<slug>` per lavori grandi), PR verso `develop`.
2. **Commit**: Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:` …).
3. **PR**: compila il template; titolo convenzionale (diventa il messaggio di squash-merge).
4. **Gate**: CI verde (secret scan + commit lint) prima del merge.
5. **Segreti**: niente credenziali, URL aziendali, email aziendali o IP privati in codice, storia o issue.
6. **Stile**: minimale, niente emoji/icone nei documenti.
