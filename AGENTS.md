# AGENTS.md — standard per tutti i repo XtremeAlex

Governance centralizzata dell'account. Prima di lavorare in QUALSIASI repo di questo account:

1. Leggi **`.ai/core.md`** di questo repo — identità, sanitizzazione, convenzioni
   (Conventional Commits, branch `develop`, naming `xtr-`, estetica minimale senza emoji), licenze, gate.
2. Leggi **`.ai/flussi.md`** — feature/release flow, caller CI, checklist nuovo progetto.
3. Regole progetto-specifiche: `.ai/` + `AGENTS.md` del repo in cui stai lavorando (se presenti) —
   prevalgono su quelle comuni solo dove più strette.

Mai pubblicare: URL Maven aziendali, email aziendali, IP privati, dati della rete di casa.
Deploy e push solo con conferma esplicita. Shell mai auto-approvata.
