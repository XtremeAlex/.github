# Support

- **Bug o richiesta di funzionalità**: apri una issue con il template (raccolta guidata).
- **Domande d'uso**: leggi prima il README del progetto e le issue chiuse; se resta il dubbio, apri una issue "question".
- **Sicurezza**: MAI in issue pubbliche — vedi [SECURITY.md](SECURITY.md).

Tempi di risposta: progetti personali mantenuti nel tempo libero; nessuna garanzia,
ma le issue ben scritte (passi per riprodurre, atteso/ottenuto, ambiente) vengono prima.
